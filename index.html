Firebase 雲端設定

為避免 Firebase API key 出現在 GitHub 原始碼，請將 Firebase Web SDK 設定貼在這裡。設定只會儲存在目前瀏覽器。

專案已正常初始化，雲端資料同步運作中。

若出現 Missing permissions 錯誤，請至 Firebase Console ➔ Firestore Database ➔ 規則 (Rules)，貼上以下內容並點擊「發布」：

rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    match /{document=**} {
      allow read, write: if request.auth != null
        && request.auth.token.email == "ericyeh@ntsu.edu.tw";
    }
  }
}
